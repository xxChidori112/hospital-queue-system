Mô phỏng JavaScript theo thuật toán của các lớp C++ trong dự án. Dùng một phòng khám mẫu để tập trung vào thứ tự lấy phần tử.

Kịch bản 20 bước: FIFO → quay vòng → mở rộng → cấp cứu → lịch sử.
Thao tác thủ công sẽ kết thúc chế độ chạy kịch bản.
Bấm “Chạy kịch bản mẫu” hoặc tự tiếp nhận bệnh nhân để bắt đầu.

01 · Queue mảng vòng

FIFO · Mức 3–5

Thêm ở cuối, lấy ở đầu. Mức 3–5 giữ thứ tự đến trong mô hình của dự án.

front = 0rear = 0count = 0capacity = 4
front: vị trí lấy tiếp theorear: vị trí thêm tiếp theo

rear = (front_ + count_) % data_.size();
data_[rear] = value; ++count_;
// Khi lấy: front_ = (front_ + 1) % data_.size(); --count_;

02 · Priority Queue

Cấp cứu · Mức 1–2

Heap theo độ ưu tiên: mức 1 trước mức 2; cùng mức thì người đến trước được gọi trước. Nút ở gốc được lấy đầu tiên.

bool operator<(const WaitingEntry& other) const {
  if (triageLevel != other.triageLevel)
    return triageLevel > other.triageLevel;
  return arrivalOrder > other.arrivalOrder;
}

Trong max-heap này, operator< đảo chiều so sánh số mức: mức 1 có độ ưu tiên cao nhất.

03 · Deque lịch sử gọi

Lượt vừa gọi được thêm vào đầu bằng push_front. Bản mẫu giữ 5 lượt; khi vượt giới hạn sẽ bỏ lượt cũ nhất bằng pop_back. Ứng dụng chính giữ 30 lượt.

Vừa lấy khỏi hàng đợi: —
callHistory_.push_front(record);
while (callHistory_.size() > historyLimit_) callHistory_.pop_back();
